# @adenyrr/astro-ui

Source visuelle partagée des sites Astro `adenyrr.me` et `docu.adenyrr.me`.

Le package fournit le chrome workstation, les thèmes clair/sombre, le mode de
lecture confortable, le fond ambiant et les tokens CSS. Les consommateurs
fournissent leur configuration et le chemin courant afin que le même composant
puisse refléter le contexte `@home` ou `@docu`.
